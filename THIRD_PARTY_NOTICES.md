## Dual-compressed photoacoustic single-pixel imaging

Yuning Guo, Baowen Li, and Xiaobo Yin, *National Science Review* 10(1),
nwac058, DOI: [10.1093/nsr/nwac058](https://doi.org/10.1093/nsr/nwac058).

The article is Open Access under the
[Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).
The original OCR/figure archive supplied to this project is attached to the
GitHub release `reference-inputs-v1`, with attribution preserved.

## Reference Python loudspeaker FEM archive

The original loudspeaker FEM archive was supplied by the project owner only
as an engineering reference for Gmsh/meshio/scikit-fem organization. Its
axisymmetric electromagnetic/structural/acoustic equations were not copied
into this model. The archive did not contain a standalone license notice, so
it is distributed as a reference release asset without granting additional
reuse rights. Users must determine their own rights before redistributing or
reusing it.
