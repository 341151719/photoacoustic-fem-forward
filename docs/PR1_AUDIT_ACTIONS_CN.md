# PR1 物理核查在 PR2 中的处理

本文件记录 2026-09-11 外部核查报告对 PR1 的主要意见，以及 PR2 的处理范围。
核查结论是：PR1 的二维初压—压力声学 FEM 主干在声明的近似下成立，但法向
平面波验收不能外推到局部圆源、斜入射、三维探头或真实编码器。

| 核查意见 | PR2 处理 |
|---|---|
| 双编码必须发生在桶积分之前 | 在内部孔径平面保留分段压力场；逐通道施加因果时延后才做相干积分 |
| 单个高斯不是随机光照序列 | 加入固定种子的非负二值图案及多个局部高斯初压基函数 |
| 编码器缺少可辨识性指标 | 输出编码/未编码算子的列相关性、奇异值、秩和条件数 |
| 双编码示例参数硬编码 | 增加配置文件 `dual` 段，控制基函数、图案、通道、孔径和时延 |
| 带宽的 FWHM 语义不清 | 明确现有 Butterworth 边缘是 −3 dB，即功率半高、幅度 \(1/\sqrt2\) |
| ADC 线性插值会混叠 | 改为带 FIR 抗混叠的 polyphase 重采样，并拒绝低于目标带宽 Nyquist 的配置 |
| 微小吸收体未进入应力约束 | 特征尺度改取光斑宽度与吸收体半径的较小者，并包含吸收体声速 |
| 元数据没有独立积分传播用初压 | 使用几何集总权重直接积分实际 `system.p0` |
| `energy_j_like` 容易被当作焦耳 | 输出改名为 `discrete_wave_energy` |
| 文档暗示已支持实测探头响应 | 明确实测 `h_tr` 输入尚未实现 |

## 尚未关闭的物理问题

- 理想通道没有固体结构、阻抗负载、损耗、色散或通道间串扰；真实编码器需要
  全波流固耦合模型或水听器标定。
- 一阶 ABC 的 −55 dB 结果只对应法向平面波。局部源和斜入射仍应使用扩大域或
  PML 对照，尤其不能把边界接收器当作完全无扰动的真实探头。
- 分片常数吸收系数形成尖锐初压边缘，没有严格有限的源频率上限；生产网格仍需
  依据目标接收带宽和实际初压图案做收敛扫描。
- 紧凑 10 MHz 双编码案例验证数据流和线性，不复现论文未公开的孔径几何，亦不
  验证 5–10 µm 三维成像分辨率。
- 目前没有光学散射传播、真实换能器脉冲响应、声衰减、三维有限面积探头和压缩
  重建。这些不应由合成峰值或条件数改善代替。

因此 PR2 的准确定位是“可运行、可审计的理想双编码前端原型”。它把论文所需的
两种编码接入 FEM 数据流，但没有把理想通道包装成已经制造或标定的物理孔径。
