# v0.2.0 / PR2

## 新增

- 多个局部高斯初压基函数和固定种子的非负随机光照图案。
- FEM 域内部的分段孔径压力采样。
- 在桶积分前施加的理想、独立、因果通道时延。
- 编码/未编码传输基、图案测量、列相关性、奇异值、秩和条件数输出。
- `pa-fem dual-forward` 命令及紧凑 10 MHz 配置。

## 根据 PR1 核查修正

- Butterworth 分数带宽明确为功率半高全宽，即 −3 dB 边缘。
- ADC 改用 polyphase FIR 抗混叠重采样，并加入目标带宽 Nyquist 检查。
- 应力/热约束和源特征频率估计同时考虑光斑与吸收体半径。
- 初压元数据直接积分实际传播场。
- 离散波动方程能量不再使用可能被误解为焦耳的名称。
- 明确普通 `validation.status` 与双编码 `status` 的适用范围。

## 实算状态

- 单元与集成测试：11 项通过。
- PR1 严格验收：5/5 组通过。
- 紧凑 10 MHz 双编码：数据流一致性通过；直接图案/基函数残差
  \(2.38\times10^{-15}\)，零时延桶积分残差为 0。
- 紧凑案例的保守特征尺度网格判据没有通过，故不作双编码波形收敛或分辨率声明。

本版本仍不包含真实固体编码板、通道损耗/串扰、实测探头响应、三维传播和压缩
重建。
