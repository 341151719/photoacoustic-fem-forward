# 双编码光声 FEM：可运行的前端版本

本版本新增随机非负光照序列和接收积分前的空间声学时延编码，并提供已计算的紧凑 10 MHz 示例。原版本的 `README_CN.md` 描述未编码基础模型，本文件描述新增模块。

实际链路：多个局部光照基函数 → 每个图案的初压 → 水/组织异质二维 FEM → 内部孔径平面的分段声压 → 各通道独立因果时延 → 单阵元压力平均 → 因果 10 MHz 带通。

这里实现的是**理想独立延迟通道孔径**：孔径前传播、衍射和空间混合由 FEM 计算，孔径后假定各通道可独立导波汇入接收器。这个通道传输假设是显式的模型组成部分，尚未由真实固体结构、损耗、阻抗或实验标定验证。它不是在已积分波形上加延迟，也没有给物体像素直接分配彼此独立的传播路径。更没有把组织声速除以论文的 g 来制造深度放大。

运行（先按原项目说明安装依赖）：

```bash
OPENBLAS_NUM_THREADS=1 python -m pa_fem.cli dual-forward \
  --config configs/dual_10MHz_compact.json --outdir results/dual_10MHz_compact
```

紧凑算例将毫米级基础几何缩小，检测频率设为 10 MHz。它用于尽快演示完整编码前端的数据流和计算结果，未宣称原论文装置尺寸、收敛精度或 5 μm/10 μm 成像分辨率。随机光照是已知的内部注量图案，没有计算光穿过散射介质的过程。没有实现压缩重建；本任务关注前端。

所有时延使用加性、因果方式处理，输出时间窗需要覆盖额外通道时延及接收响应。压力量仍以 Pa 表示，未引入未经标定的 V/Pa 电压增益。编码是否改善分辨能力必须看计算出的传输矩阵和噪声条件，不预设必然改善。

输出中的光照基函数系数、空间孔径响应及编码/未编码波形足以复查链路。原有基础求解器命令保持可用。版本的模型说明和实算摘要以本文件及输出 JSON 为准。
PR1 核查意见及其在本版本中的处理边界见 `docs/PR1_AUDIT_ACTIONS_CN.md`；可提交的实算摘要见 `docs/reference/dual_10MHz_compact_summary.json`。

本算例默认采用 6 个局部高斯光照基函数、16 个固定随机种子的二值系数图案，以及 8 个空间孔径通道；这些数量、孔径位置、积分阶数和时延范围均在配置文件的 `dual` 段中定义。它演示前端，不将 16/6 的小型测试称为压缩成像性能。由于系统线性，FEM 同时计算各光照基函数的响应，再组合成全部图案的波形；另将第一个完整图案作为独立初压同时推进，检查它与基函数组合一致。8 个孔径通道的输入均来自每个源经过 FEM 传播后的混合声场，并非一个物体像素对应一个孔径通道。

输出文件：

- `dual_data.npz`：光照系数、初压基函数、网格、各孔径通道的时间响应、通道延迟、编码/未编码传输基和 16 条测量波形。波形数组布局是 `[time, pattern]`，孔径场布局是 `[FEM time, channel, optical basis]`。
- `dual_comparison.png`：随机光照序列、通道延迟以及相同光照下有/无编码的波形。
- `summary.json`：参数、峰值、两类波形差异、传输列相关性/奇异值/条件数和实际数值一致性检查。
- `mesh.msh`：此次实际使用的 FEM 网格。

孔径是单向、无负载的内部声压采样面；通道对入射场的反作用没有计算。记录结束后对孔径波形补零，接收记录延长以容纳编码延迟和滤波尾波；若做长时高精度研究，应同时延长 FEM 本身的传播时间。空间平滑、有限网格和假设接收带宽仍限制微结构信息，本算例不据峰值或波形差异推断成像分辨率改善。

2026-09-11 在仓库锁定环境中实算：53,171 自由度，1,601 个 FEM 时间点，3,752 个输出时间点，求解及数据组装约 45.95 秒。16 个图案中的未编码最大绝对峰值为 511.70 Pa，编码后为 133.38 Pa；峰值降低来自时延造成的叠加变化，不能单据此判定信噪比或分辨率优劣。完整图案直接传播与基函数组合的相对误差为 2.38e-15；零差分时延的孔径求和误差为 0。

编码算子的最大列相关性仍为 0.9984、条件数约 4.17e4；未编码算子相应为接近 1 和 1.05e6。编码改变并改善了这个小例的条件数，但算子依然高度相关，不能由此声称已经实现稳健的亚波长辨识。此次运行使用 Python 3.12.3、NumPy 2.5.3、SciPy 1.18.1、scikit-fem 12.0.2、Gmsh 4.15.2、meshio 5.3.5。此次只做必要的一致性与运行检查，没有展开双编码算子的网格、通道数或噪声收敛扫描。

本次网格的 95% 边长为 7.87 µm，而按 10 µm 光斑特征尺度给出的保守建议为 2.09 µm，比例为 3.76，因此 `characteristic_resolution_met=false`。这里的 `status=pass` 只表示数据流、有限值和线性叠加一致性通过，不表示该双编码波形已经空间收敛。
